# Build-tool integrations

Compdi must transform macro calls before they reach runtime. Choose the adapter for your build tool.

| Build tool | Import | Setup |
| --- | --- | --- |
| Vite | `compdi/plugin/vite` | [Vite guide](/integrations/vite) |
| Rollup | `compdi/plugin/rollup` | [Rollup guide](/integrations/rollup-and-rolldown) |
| Rolldown | `compdi/plugin/rolldown` | [Rolldown guide](/integrations/rollup-and-rolldown) |
| Rspack | `compdi/plugin/rspack` | [Rspack guide](/integrations/rspack-and-esbuild) |
| esbuild | `compdi/plugin/esbuild` | [esbuild guide](/integrations/rspack-and-esbuild) |

The default file filter includes JavaScript and TypeScript variants matching:

```txt
\.[cm]?[jt]sx?$
```

You can override it with the plugin's `include` option:

```ts
compdi({ include: /\.ts$/ })
```

::warning
If a macro throws at runtime, confirm that the adapter is registered and that the source file matches `include`.
::
