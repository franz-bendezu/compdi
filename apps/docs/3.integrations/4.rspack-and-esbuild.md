# Rspack and esbuild

## Rspack

```js [rspack.config.js]
const compdi = require("compdi/plugin/rspack").default;

module.exports = {
  plugins: [compdi()],
};
```

## esbuild

```ts [build.ts]
import { build } from "esbuild";
import compdi from "compdi/plugin/esbuild";

await build({
  entryPoints: ["src/index.ts"],
  bundle: true,
  plugins: [compdi()],
});
```

The esbuild adapter requires an esbuild API that supports plugins.
